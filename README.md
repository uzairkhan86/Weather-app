# Weather App

A website that shows the live weather for any city, with an animated sky background (glowing sun and moving clouds).

**Live demo:** https://uzairkhan86.github.io/weather-app/

## Features
- Search any city in the world
- Shows temperature, weather condition, humidity and wind speed
- Press Enter or click Search
- Handles errors (city not found, no internet)

## Technologies
- HTML, CSS, JavaScript
- Open-Meteo API (free, no API key needed)

## How to run
Download `index.html` and open it in your browser.

## What I learned
- Building a web page with HTML, CSS and JavaScript
- Getting live data from an API with `fetch`
- Making animations with CSS
